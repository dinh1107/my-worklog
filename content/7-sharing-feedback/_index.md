# SHARING AND FEEDBACK

## Overall assessment

**1. General evaluation**  
Participating in the **First Cloud AI Journey (FCAJ)** program was a valuable learning experience that introduced AWS through a progression from foundational knowledge to hands-on practice. Combining learning materials, labs, and a final project helped me understand how AWS services can be applied to a specific problem.

**2. Learning content**  
The program provided a useful foundation in cloud computing, security, storage, monitoring, and serverless architecture. Through the smart home project, I learned how to combine multiple services into a complete data pipeline instead of working with each service in isolation.

**3. Community support**  
Technical content shared by FCAJ mentors and community members was a useful reference throughout the learning process. Practical guidance and experience helped me develop a better approach to documentation, troubleshooting, and solution selection during project implementation.

**4. Hands-on experience**  
The practical work helped me understand access management with IAM, MQTT ingestion with AWS IoT Core, processing with Lambda, storage in DynamoDB, notifications through SNS, and system monitoring with CloudWatch. I also gained experience storing reports in S3 and automating daily tasks with EventBridge Scheduler.

**5. Skills gained**  
Through the program and project implementation, I improved my:

- Foundational knowledge of AWS Cloud.
- Ability to design hybrid Edge and Cloud IoT architectures.
- Understanding of least-privilege access with IAM.
- Ability to build and test serverless processing pipelines.
- Log analysis and troubleshooting skills.
- Technical documentation skills using Markdown.
- Self-learning and official documentation research skills.

## Suggestions

- Add more hands-on exercises that connect several AWS services in one architecture.
- Provide more real-world troubleshooting scenarios involving IAM, Lambda, CloudWatch, and service integration.
- Organize additional sessions on security, cost optimization, and scalable system design.
- Add introductory content about Infrastructure as Code and automated deployment workflows.
- Create more opportunities for learners to present projects, receive feedback, and exchange practical experience.

---

## Final thoughts

I appreciate the knowledge, learning materials, and direction provided by the **First Cloud AI Journey** program. Completing the learning activities and project gave me a clearer understanding of how AWS services work together in a practical system and motivated me to continue developing my skills in **Cloud Computing and the Internet of Things**.

The project still has room for improvement in scalability, security, and monitoring, but it provides an important foundation for further learning, hands-on practice, and the development of more complete solutions in the future.
