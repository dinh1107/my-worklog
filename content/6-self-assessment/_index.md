# SELF-ASSESSMENT

During the **First Cloud AI Journey (FCAJ)** program, I gained cloud computing knowledge through AWS learning materials, hands-on labs, technical workshops, and self-study. I applied this knowledge to extend a locally operated smart home system into a hybrid edge and AWS Cloud solution.

Through the project, I gained practical experience with IAM, AWS IoT Core, Lambda, DynamoDB, SNS, CloudWatch, S3, EventBridge Scheduler, and AWS Budgets. The completed system receives MQTT data, processes and stores telemetry, sends email alerts, monitors operations, and automatically exports daily JSON and CSV reports.

In addition to technical knowledge, I improved my skills in requirements analysis, architecture design, access management, troubleshooting, and bilingual technical documentation. The implementation process gave me a clearer understanding of how IoT devices, a gateway, and serverless AWS services can work together in a complete data pipeline.

## Areas for improvement

- Develop a deeper understanding of scalable and fault-tolerant AWS architecture design.
- Adopt Infrastructure as Code to make deployments repeatable and reduce manual configuration errors.
- Optimize the DynamoDB data model and report queries for larger numbers of devices and records.
- Strengthen security through local MQTT TLS, certificate rotation, and protected firmware updates.
- Add an SQS dead-letter queue, CloudWatch Alarms, load testing, and data-recovery scenarios.
- Improve time management, technical presentation, and teamwork skills for larger projects.

## Conclusion

The FCAJ program strengthened my AWS foundation and practical skills through an end-to-end project. I learned not only how to use individual services, but also how IAM, IoT Core, Lambda, DynamoDB, SNS, CloudWatch, S3, and EventBridge work together in a serverless architecture.

The project met the course objectives and created a foundation for further study in Cloud, IoT, and event-driven architecture. The current system is appropriate for learning and demonstration; a real-world deployment would require further improvements in scalability, monitoring, security, and disaster recovery.
